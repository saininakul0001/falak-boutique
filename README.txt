Silai Planner PWA - Android installation

1. Upload all files in this folder to a GitHub Pages repository root.
2. In repository Settings > Pages, deploy from main branch /root.
3. Open HTTPS GitHub Pages URL in Android Chrome.
4. Menu (three dots) > Install app or Add to Home screen.
5. Open once online, then test airplane mode. Google Fonts may fall back to system fonts offline. WhatsApp sharing requires internet.

IMPORTANT: Orders remain in this device/browser storage. Clearing site data or uninstalling can erase orders. Back up data before changing phones. Hosting the app does NOT back up orders.
